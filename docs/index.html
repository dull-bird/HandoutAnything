HandoutAnything: Local Materials → Handout

Given any local material — textbook/PDF (digital or scanned), local video with subtitles, audio, Markdown/text, papers, or a mixed corpus on one theme — distill it into a structured, first-principles study handout. Full methodology in handout-anything/references/handout-methodology.md.

🚦

Suitability Gate

Not everything deserves a handout. Fiction-for-enjoyment is a red light (suggest a reading guide instead); non-fiction, courses, papers are green; mixed corpora get a problem tree first.

⚖️

Load Calibration

One unit = 60–90 min of digestible content. Density factors differ by discipline: 1 concept+proof for math/physics, 2–3 angles for philosophy, 3–5 concepts for reading-heavy subjects. 7±2 units per weekly handout.

🧭

Hub Concepts

Concepts scored by dependency count, derivational power, cross-domain reuse, and definitional depth. Hubs get full treatment: derivation + figure + pitfalls + exercises.

🌱

First Principles + Feynman

Definitions are designed, not discovered — teach the design motive. Every abstraction gets an everyday analogy; derivations replace memorization; comparisons stay objective with validity boundaries.

📐

Figure Discipline

Quantitative consistency (a figure is a measurable claim), properties by construction (never eyeballed), and every symbol must be introduced in the text.

✅

Verification Checklist

Zero compile errors, no silently dropped glyphs, page-by-page visual inspection, coverage check against the concept list, and an explicit scope statement of what the handout does NOT cover.

Clone https://github.com/dull-bird/HandoutAnything,
read handout-anything/SKILL.md and
handout-anything/references/handout-methodology.md, then
follow the workflow to turn <LOCAL_FILE_OR_FOLDER>
into a handout: suitability gate and pre-flight checks
first, show me the unit plan for confirmation before

verification checklist.

Course downloads (separate plugins)

opencli

Downloading from MOOC platforms is out of scope here — use the dedicated opencli plugins. Their output feeds this repo as local material:

opencli plugin install \
  github:/opencli-plugin-coursera
opencli plugin install \
  github:/opencli-plugin-hf-learn

opencli coursera download "URL" --out ./notes
opencli hf-learn read llm-course chapter1/1 \
  --out chapter1-1.md
