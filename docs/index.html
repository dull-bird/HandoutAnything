mooc2handout

One-click pipeline: download MOOC subtitles & videos, AI-infers keyframes, extracts frames, and scaffolds structured handouts.

Coursera edX (planned) FutureLearn (planned) more coming...

How It Works

1
📥

Download

Subtitles (VTT) + 720p video + supplementary PDFs via opencli

2
🧠

AI Keyframes

Semantic analysis of VTT text detects concept shifts, definitions, examples

3
📷

Extract Frames

ffmpeg cuts screenshots at predicted timestamps

4
📖

Handout

LaTeX scaffold with keyframe images, structured notes, exercises

Features

🌐

Multi-Platform

Currently supports Coursera with full auto-discovery. edX and FutureLearn adapters planned.

🔒

Lock Detection

Automatically detects locked lectures and skips them gracefully.

📄

Supplementary Materials

Downloads background reading PDFs, slide decks, and other resources attached to lectures.

🤖

AI Keyframe Inference

Bilingual (CN/EN) semantic analysis: concept shifts, definitions, examples, summaries.

🎬

Video Integration

720p download via yt-dlp, DOM src, or network intercept with HLS fallback.

⚡

Zero Password

Uses your logged-in Chrome session. No credentials stored or transmitted.

Manual Install

CLI 
# 1. Install opencli
npm install -g @jackwener/opencli

# 2. Install adapter
mkdir -p ~/.opencli/clis/coursera
cp skill/download.js ~/.opencli/clis/coursera/

# 3. Download with resources
opencli coursera download "URL" \
  --video --resources --locale en

# 4. Infer keyframes
python3 scripts/vtt_keyframes.py \
  --vtt-dir ./notes/module-1 \
  --output keyframes.json

# 5. Extract frames
python3 scripts/extract_frames.py \
  --video-dir ./notes/module-1 \
  --keyframes keyframes.json \
  --output ./frames/
