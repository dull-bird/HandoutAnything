mooc2handout

One-click pipeline: download MOOC subtitles & videos, AI-infers keyframes, extracts frames, and scaffolds structured handouts.

Coursera edX (planned) FutureLearn (planned) more coming...

How It Works

1
📥

Download

Subtitles (VTT) + 720p video + supplementary PDFs via opencli

2
🧠

AI Keyframes

Semantic analysis of VTT text detects concept shifts, definitions, examples

3
📷

Extract Frames

ffmpeg cuts screenshots at predicted timestamps

4
📖

Handout

LaTeX scaffold with keyframe images, structured notes, exercises

Features

🌐

Multi-Platform

Currently supports Coursera with full auto-discovery. edX and FutureLearn adapters planned.

🔒

Lock Detection

Automatically detects locked lectures and skips them gracefully.

📄

Supplementary Materials

Downloads background reading PDFs, slide decks, and other resources attached to lectures.

🤖

AI Keyframe Inference

Bilingual (CN/EN) semantic analysis: concept shifts, definitions, examples, summaries.

🎬

Video Integration

720p download via yt-dlp, DOM src, or network intercept with HLS fallback.

⚡

Zero Password

Uses your logged-in Chrome session. No credentials stored or transmitted.

HandoutAnything: Local Materials → Handout

Given any local material — textbook/PDF (digital or scanned), local video with subtitles, audio, Markdown/text, papers, or a mixed corpus on one theme — distill it into a structured, first-principles study handout. Full methodology in references/handout-methodology.md.

🚦

Suitability Gate

Not everything deserves a handout. Fiction-for-enjoyment is a red light (suggest a reading guide instead); non-fiction, courses, papers are green; mixed corpora get a problem tree first.

⚖️

Load Calibration

One unit = 60–90 min of digestible content. Density factors differ by discipline: 1 concept+proof for math/physics, 2–3 angles for philosophy, 3–5 concepts for reading-heavy subjects. 7±2 units per weekly handout.

🧭

Hub Concepts

Concepts scored by dependency count, derivational power, cross-domain reuse, and definitional depth. Hubs get full treatment: derivation + figure + pitfalls + exercises.

🌱

First Principles + Feynman

Definitions are designed, not discovered — teach the design motive. Every abstraction gets an everyday analogy; derivations replace memorization; comparisons stay objective with validity boundaries.

📐

Figure Discipline

Quantitative consistency (a figure is a measurable claim), properties by construction (never eyeballed), and every symbol must be introduced in the text.

✅

Verification Checklist

Zero compile errors, no silently dropped glyphs, page-by-page visual inspection, coverage check against the concept list, and an explicit scope statement of what the handout does NOT cover.

install opencli, install the platform adapter,

Manual Install

CLI 
# 1. Install opencli
npm install -g @jackwener/opencli

# 2. Install adapter
mkdir -p ~/.opencli/clis/coursera
cp skill/download.js ~/.opencli/clis/coursera/

# 3. Download with resources
opencli coursera download "URL" \
  --video --resources --locale en

# 4. Infer keyframes
python3 scripts/vtt_keyframes.py \
  --vtt-dir ./notes/module-1 \
  --output keyframes.json

# 5. Extract frames
python3 scripts/extract_frames.py \
  --video-dir ./notes/module-1 \
  --keyframes keyframes.json \
  --output ./frames/
