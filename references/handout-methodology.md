# 从任何来源到讲义：方法论模板

本文件是 to-handout 方法论的核心模板。它回答五个问题：

1. 这份材料**适不适合**做成讲义？（适用性边界）
2. 一份讲义**应该装多少知识**？（知识量标定）
3. 如何从材料里**拆出知识、找到重点**？（拆解与枢纽识别）
4. 怎样**讲得让人真懂**？（讲解原则）
5. 成品如何**组织与把关**？（结构模板与验证清单）

---

## 0. 适用性边界：先决定做不做

讲义的本质是**把非虚构知识重新组织为可教学的结构**。三类来源，三种处理：

### 0.1 直接适合（绿灯）

- 教材、课程（视频/PPT/音频）、讲义、文档、规范
- 非虚构书籍（科普、技术、历史、社科）
- 论文（单篇、多篇、综述）、技术博客、报告

特征：内容的目的是**传递知识或论证**，读者期待"学完能带走东西"。

### 0.2 条件适合（黄灯，需重新定义目标）

- **虚构作品用于研究目的**：小说、诗歌、电影作为**文学研究/批评对象**时可以做讲义——此时讲义的主题不是作品本身，而是"关于作品的知识"（叙事结构、主题分析、流派背景）。
- **主题混合语料**：多篇论文、博客、播客围绕同一主题——可以做，但要先建"问题树"（见 2.3），而不是逐篇摘要。
- **严重过剩的材料**： encyclopedia 式巨著——可以做，但必须明确"本讲义覆盖什么、不覆盖什么"（边界声明）。

### 0.3 不适合（红灯，明确拒绝并说明理由）

- **虚构作品用于欣赏目的**：把《活着》做成"知识点讲义"是对作品的降维——它的价值在体验与共鸣，不在可提取的命题。此时应建议替代产物（书评、导读、人物关系图）。
- **纯操作日志/流水账**：没有概念结构可提取的原始记录。
- **信息密度过低**：内容总量撑不起一个学习单元（此时建议做成单页摘要而非讲义）。

**边界判断的输出必须显式化**：每个讲义项目开工前，写下"为什么这份材料适合做讲义"一句话。写不出来，就是红灯。

## 1. 起飞前检查

- **可提取性**：PDF 用 `pdfinfo` 元数据 + 试取几页文本判断数字版还是扫描件；扫描件放弃文本管道，改视觉读取关键页或 OCR。视频/音频先确认字幕或转写渠道。
- **版本与来源**：同名教材有新旧课标、不同出版社之分；目录页是最快的版本指纹。论文确认是预印本还是正式版。
- **结构化程度**（决定 2.x 的策略）：材料是"已被教师/作者编排好的"（课程、教材），还是"原始堆积的"（论文集、博客合集）？

## 2. 知识量标定：一份讲义该装多少

### 2.1 基本单元

一切讲义以**学习单元**为积木：

> 1 个学习单元 = 普通目标读者 60–90 分钟可消化的内容
> = 1 个核心概念 + 3–5 个支撑要点 + 1 幅图/推导 + 2–4 题自测

### 2.2 学科密度系数

不同学科，"一个单元"能装的概念数量差异极大，按主导认知方式分类：

| 类型 | 例子 | 单元容量 | 单元设计要点 |
|---|---|---|---|
| 计算/推导型 | 数学、物理 | 1 个核心概念（含推导） | 推导必须完整呈现，自测含计算 |
| 理解/思辨型 | 哲学、理论、思想史 | 1 个核心概念（多角度例证） | 同一概念给 2–3 个切入角度，自测重辨析 |
| 阅读/记忆型 | 历史、生物、地理 | 3–5 个关联概念 | 用结构图/年表组织，自测重回忆与联系 |
| 技能/操作型 | 编程、实验、工具 | 1 个技能点 + 演示 | 步骤化，自测为动手任务 |

一个难点概念（如极限、加速度、存在主义）**一个就够一个单元**；不要按材料的页数均分。

### 2.3 按来源类型定策略

- **已编排源**（课程视频、大学课程）：教师的"讲"就是天然单元，1 讲 ≈ 1 单元，沿用其划分，你的工作是压缩而非重排。
- **书**（教材、非虚构）：**不照章办事**。章是作者的组织，不是读者的路径。做法：先按第 3 节拆出概念地图，再按"读者差集 + 枢纽概念"重新划分单元——可以合并三章为一单元，也可以把一章拆成三单元。
- **混合语料**（多篇论文/博客围绕一主题）：先建**问题树**（这个主题要回答哪几个问题？），每篇材料映射到问题节点，单元按问题而非按材料划分。综述性材料优先作为骨架，单篇论文作为论据。
- **论文单篇**：背景（问题从何而来）→ 主张（一句话）→ 方法（怎么论证/实现）→ 证据 → 局限与边界。警惕"作者的一面之词"：方法适用条件、基线是否公平、威胁有效性，必须进讲义。

### 2.4 总量控制

- 一份"一周讲义"：**7 ± 2 个单元**，总自测 20–30 题。
- 超出就砍：先砍非枢纽概念，再砍单元数量，**不砍推导和易错点**。
- 明确**边界声明**：讲义末尾写清"本讲义覆盖/未覆盖什么"，被砍的内容列进"后续学习指引"。

### 2.5 工作量估计与校准（禁止拍脑袋报时）

单元时间（"60–90 分钟"）必须**从产物实际体积算出来**，不能先写时间再凑内容。估计公式：

```
单元工作量 = 正文阅读时长 + 推导跟进时长 + 自测时长
  正文阅读时长 = 正文字数 ÷ 阅读速度（中文非虚构 300–500 字/分钟；思辨/数学取慢档 250–300）
  推导跟进时长 = 推导/例题段落数 × 3–5 分钟（读者要动笔跟推才算"读了"）
  自测时长     = 题数 × 2–5 分钟（辨析题低档，计算/讲解题高档）
```

执行规则：

1. **写完再报**：初稿完成后按上式逐单元计算，把估计值标在单元开头（"本讲约 25 分钟"），全书合计标在"开始前"页。报 60–90 分钟但正文只有两页的单元，必须改报实值或补内容。
2. **按实标名**：总工作量不足 8 小时的讲义，单元叫"第 N 讲"；能撑满一周每天 1 小时以上的才叫"第 N 天"。
3. **校准回流**：读者反馈的实际耗时与估计偏差超过 50% 时，调整阅读速度档位并记录，供下一份讲义使用。

### 2.6 单元元数据：难度与优先级

单元之间的价值与难度**不可能均等**，必须在讲义中显式分层：

- **优先级**：【必看】（全书价值锚点，跳过则主线断裂）/【建议】（主线组成部分）/【可选】（加深或拓展，可跳过不影响后续）。依据：枢纽概念打分（§3.1）+ 依赖图上的位置。
- **难度**：★–★★★ 三级，按认知类型标（纯记忆 ★，概念理解 ★★，抽象/反直觉/多步推导 ★★★）。
- 标注位置：单元标题行；并在"开始前"页给出**依赖关系图**（各单元之间的前提箭头与必看路径），让读者一眼看到轻重缓急与阅读顺序的灵活性。

## 3. 知识拆解：从材料到概念地图

四步流程：

1. **结构提取**：目录、章节标题、字幕段落、幻灯片标题——得到材料的"骨架清单"。
2. **概念清单**：逐节提取定义、定理、公式、方法、术语，记精确口径（符号、条件、适用范围）。
3. **读者差集**：对照目标读者的已有知识（如"初三毕业生"），把概念分为【已会】【升级】【全新】。讲义火力集中在【全新】，【升级】用于衔接，【已会】只在需要时点名。**给初学者讲已会的内容是最常见的篇幅浪费。**
4. **概念地图**：标注概念间的依赖关系（A 是 B 的前提），得到有向图——单元的划分与排序必须尊重依赖方向。

### 3.1 枢纽概念识别（"一通百通"判据）

对概念清单逐项打分（每项 0–2 分），高分者就是讲义的骨架：

- **被依赖度**：多少后续概念以它为前提？（如：加速度 → 匀变速 → 牛二）
- **衍生力**：多少公式/结论能从它直接推出？（如：基本不等式 ← 平方非负）
- **跨域复用**：同一思想是否在多处换装出现？（如：极限思想 = 瞬时速度 = 无理指数 = 二分法；作差法 = 不等式 = 单调性）
- **第一性深度**：它是否回答了"为什么这样定义"？（如：对数 = 指数方程的反解）

枢纽概念享受最高待遇：完整推导 + 图 + 易错点 + 自测全覆盖。非枢纽概念只给定义和一句话直觉。

### 3.2 单元排序原则

- 依赖优先：前提概念必须先讲。
- 悬念驱动：能在前一单元结尾埋下"为什么 X 里的字母和后一天的现象有关"这类钩子，就埋。
- 闭环收束：最后一个单元把全讲义的主线方程/主线图"焊起来"，并回答开篇提出的核心问题。

## 4. 讲解原则：怎样讲得让人真懂

1. **第一性原理优先**：每个定义都追问"为什么这样设计"。定义是被设计的，不是被发现的——讲清设计动机（如"按运算规则不变来定义指数"），结论就不用背。
2. **费曼检验**：写作时假设读者是聪明的零基础外行。术语出现必须先解释；每个抽象概念配一个日常类比；写完自问"我妈能看懂这段吗"。
3. **推导替代背诵**：公式能从定义和图象推出的，一律当场推一遍；明确指出"这条不用背，是 X 的推论"。
4. **客观对比**：对比两个方法/流派/概念时，给出各自的成立条件与适用边界，不拉踩。"A 在什么情况下优于 B，什么情况下反过来"。
5. **风险点视角**：每个核心概念配"易错点/失效边界"框——它什么时候被误用、常见的错误直觉是什么、结论在什么条件下失效。（例：静摩擦不能套公式；存在定理不保证唯一；对数对加法没有法则。）
6. **观点溯源**：转述材料观点时区分"材料主张"与"讲义作者的判断"；论文类材料必须标注主张的证据强度。
7. **讲解即检测**：每单元结尾的自测里，至少一题要求读者"用自己的话讲/向别人解释"——费曼出口。

## 5. 结构模板

### 5.1 讲义级结构

```
封面（标题 / 对象 / 依据来源 / 边界声明）
目录
开始前：这份材料在讲什么（两问题地图）+ 本讲义的三样工具 + 学法说明
单元 1 … 单元 N
串讲/总检验（可选，N ≥ 5 时建议）
参考答案
收尾："学完你应该能讲给别人听的 N 句话"
```

### 5.2 单元级结构（每一天/每一讲）

```
核心问题（一句话，回答"这单元解决什么困惑"）
2–3 个小节：
  · 第一性讲解（定义的设计动机 → 精确定义 → 直觉类比）
  · 公式/图象/推导（能推则推，配定量自洽的图）
  · 易错点与失效边界（风险点框）
今日自测（2–4 题，题型见 5.3）
```

### 5.3 练习设计

- **题型配比**（每单元）：概念辨析（40%）+ 直接应用/计算（30%）+ 反例或判断（15%）+ 讲解输出（15%，"向初中生解释为什么…"）。
- **难度阶梯**：第一题直用定义，中间题需一步变形，最后一题需迁移或表达。
- **答案给思路要点**，不只给结果：关键步骤、为什么这样做、常见错法点名。
- 总检验覆盖全部单元，至少一题"画出本讲义的知识地图"。

### 5.4 图示规范（本仓库三次实战教训固化）

1. **定量自洽**：图中被公式标注的几何量（长度、角度、交点）必须成比例成立——图本身就是一条可测量的论证。
2. **由构造保证**：依赖几何性质的图（交点、闭合、切点），用带预定性质的解析式/坐标构造，再数值验证，不靠目测摆点。
3. **记号有交代**：图中每个符号必须在正文有出处；找不到出处的记号，要么补写，要么删掉。
