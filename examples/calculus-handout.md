# 微积分核心概念速览（应用心理学·大一适用）

> 配套主教材：**《普林斯顿微积分读本》（The Calculus Lifesaver, Adrian Banner）**
> 定位：一份"建立直觉 + 抓住主干"的讲义，不追求刷题量。文科版高数考试范围基本不出本文。

---

## 0. 一句话总纲

微积分只研究两件事：

- **微分（求导）**：某一点上，变化有多快？→ 变化率、斜率
- **积分**：把无数微小的变化累积起来，总量是多少？→ 面积、累积量

而**微积分基本定理**说：这两个操作互为逆运算。整门课就是在把这句话展开。

心理学直觉：学习曲线某一时刻的"进步速度"是导数；一段时间练习累积的"总熟练度"是积分。

---

## 1. 函数与极限（第 1–2 周）

### 函数
- 函数 = 输入→输出的规则。重点熟悉：多项式、指数 eˣ、对数 ln x、三角函数 sin/cos。
- 会看图像：定义域、单调性、对称性。

### 极限（lim）——全课程的地基
- **直觉**：x 无限靠近 a 时，f(x) 无限靠近的那个值。不要求到达，只看趋势。
- 记法：lim(x→a) f(x) = L
- **必须会的三件事**：
  1. 直接代入能算就代入；
  2. 代入出 0/0 → 因式分解或约分再代入；
  3. x→∞ 的有理函数 → 只看最高次项的比。
- 连续 = 图像不断开 = 极限值等于函数值。

> 易错点：极限存在 ≠ 函数在该点有定义。极限只问"靠近时去哪儿"。

---

## 2. 导数（第 3–5 周，全课重心）

### 定义与意义
- **定义**：f′(x) = lim(h→0) [f(x+h) − f(x)] / h
- **几何意义**：曲线在该点切线的斜率。
- **物理/心理意义**：瞬时变化率（反应时随练习次数下降的速率、人口增长速度）。

### 基本公式（背熟）
| 函数 | 导数 |
|---|---|
| xⁿ | n·xⁿ⁻¹ |
| eˣ | eˣ（它自己是自己的导数） |
| ln x | 1/x |
| sin x | cos x |
| cos x | −sin x |
| 常数 C | 0 |

### 求导法则
- 和差、常数倍：逐项求。
- **乘法法则**：(uv)′ = u′v + uv′
- **商法则**：(u/v)′ = (u′v − uv′) / v²
- **链式法则**（最重要）：复合函数 f(g(x)) → 外导 × 内导：f′(g(x))·g′(x)

### 导数的应用（考试大题出处）
- f′(x) > 0 → 增；f′(x) < 0 → 减；f′(x) = 0 且变号 → 极值点。
- **求极值/最值三步**：求导 → 解 f′(x)=0 得驻点 → 判断两侧符号（或看二阶导 f″ 正负）。
- 二阶导 f″：判断凹凸（f″>0 凹向上，像微笑）。

## 3. 积分（第 6–8 周）

### 不定积分
- **直觉**：求导的反操作。∫f(x)dx = "哪个函数求导等于 f(x)" + C（常数 C 别丢）。
- 基本公式就是导数表倒着读：∫xⁿdx = xⁿ⁺¹/(n+1) + C（n ≠ −1）；∫(1/x)dx = ln|x| + C；∫eˣdx = eˣ + C。

### 定积分
- **直觉**：曲线下方的面积 = 无数个细窄条面积之和。
- 记法：∫ₐᵇ f(x)dx，几何上 = 从 a 到 b 的"净面积"。

### 微积分基本定理（全课最高光）
> ∫ₐᵇ f(x)dx = F(b) − F(a)，其中 F 是 f 的任意一个原函数。

**意义**：算面积这种"无限求和"的难题，变成"找一个原函数，做两次减法"。这就是微分和积分互为逆运算的精确表述，也是这门课叫"微积分"的原因。

### 一个最常用的技巧：换元积分
- 看到复合结构（如 ∫2x·e^(x²)dx），令 u = x²，du = 2x dx，积分立刻变简单。文科版掌握这一种就够。

## 4. 一张图记住整门课

```
        求导（变化率）
  函数 f(x) ──────────→ 导数 f′(x)
     ↑                      │
     └──── 积分（累积） ←────┘
        微积分基本定理：两者互逆
```

- 极限 → 是定义导数和积分的工具；
- 导数 → 局部变化率；积分 → 整体累积量；
- 基本定理 → 把两者焊死在一起。

## 5. 学习路径建议（2 周速通 / 一学期跟课两用）

1. **直觉先行**：3Blue1Brown《微积分的本质》前 5 集（B 站有中配），半天看完，建立图像直觉。
2. **主攻教材**：《普林斯顿微积分读本》只需读：
   - 第 1–6 章：极限与连续
   - 第 7–9 章：求导（链式法则是关键）
   - 第 11 章：导数应用（极值问题）
   - 第 14、16–18 章：积分与基本定理、换元法
   - （级数、泰勒展开等后面的章节文科版不考，跳过）
3. **练习量**：每节做 5–10 道课后题即可，重点是**能讲清楚每个符号在说什么**，而不是计算速度。
4. **应试兜底**：开学后把学校发的文科高数教材的例题过一遍，对齐本校考试的题型和记号习惯。

## 6. 常见误区

- ❌ 把极限当成"代入"——代入只是求极限的一种手段。
- ❌ 丢了不定积分的 +C——考试必扣分。
- ❌ 死记求导公式不理解"变化率"——到了心理统计（回归斜率、似然函数求极值）会接不上。
- ❌ 一上来啃同济版《高等数学》——那是理工科应试体系，自学体验差；普林斯顿读本读完后再回头翻它当工具书用。
