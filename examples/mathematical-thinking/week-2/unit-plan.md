## 1. 逐讲概念清单

### 01 · Lecture 3: Implication（正课，Devlin 自称"全课程最难的部分"）

**核心概念：条件句（conditional / material conditional）——蕴含的"真值部分"**

- 精确口径：
  - 日常"如果…那么…"（implication）= **真值部分 + 因果部分**。数学只保留真值部分，命名为 conditional（物质条件句），Devlin 用双箭头 ⇒（声明：许多教材用单箭头，本课程为避免歧义坚持用双箭头）。
  - φ ⇒ ψ 中 φ 叫 antecedent（前件），ψ 叫 consequent（后件）。
  - 真值表：**仅当 φ 真 ψ 假时为假，其余三种情况均为真**（T F T T）。
  - 假前件 ⇒ 条件句恒真（vacuous truth；**字幕未出现该术语，属作者补充**）。
- 关键论证链（必须进正文）：
  1. 因果问题的暴露：√2 是无理数（真）、0<1（真），但前者推不出后者——∧、∨ 不需要两子句有任何关系（"凯撒已死 ∧ 1+1=3"照样有真值），蕴含却涉及因果，而因果是哲学家吵了几代人的难题。
  2. 设计动机（第一性）：扔掉因果部分后，条件句**永远有定义**；且在"真有蕴含"的情形下，条件句的真值行为与真蕴含一致。数学中"把定义域扩展到所有情形、只要在有意义的情形上行为正确"是常规操作。
  3. 真值表第二行（T,F→F）的推导：反证——若此处为 T 且视为真蕴含，则 ψ 真应从 φ 真推出，与 ψ 假矛盾。
  4. 真值表第三、四行（假前件）的推导：人对假前件没有直觉，转向分析"φ does not imply ψ"——它只在"φ 真而 ψ 假"时成立；取否定即得条件句在后两行为真。**这是全讲最绕的一段推导**。
- Devlin 强调的反直觉点：
  - "凯撒已死 ⇒ π>3"按条件句为真，尽管毫无意义——但这不会出问题，因为数学实践中不会遇到这种无关联情形。
  - 这个"永远有定义"的性质是飞机控制系统软件依赖的基础——"毫不夸张地说，你的命都靠它"。
  - Devlin 反复预警：这部分可能要看好几遍视频才能想通，"可能是全课程最难的东西"。
- 讲内小测（可转化为自测）：
  - ∧/∨ 与蕴含的差别（凯撒+1+1=3：合取假、析取真）。
  - 条件句真值由什么定义？（答：仅由前后件真值，与因果无关）。
  - 四种真值组合中哪些使 φ⇒ψ 为真？（答：TT、FT、FF 三种）。
  - 结课小测：π²>2 ⇒ π>1.2（真，且对任意正数成立，属真蕴含）；π²<0 ⇒ π=3（假⇒假，真）；某 T⇒F 项（假）；"如果三角形有四条边则正方形有五条边"（假⇒假，真）；"如果欧几里得生日是某天则矩形有四条边"（后件真，故无论前件真假都真）。

### 02 · Lecture 4: Equivalence（正课，较短）

**核心概念 A：等价与双条件（biconditional）**

- 精确口径：φ、ψ 逻辑等价 ⟺ 互相蕴含。双条件 φ⇔ψ 定义为 (φ⇒ψ) ∧ (ψ⇒φ) 的缩写；真值表：两真值相同（TT 或 FF）时为真。
- Devlin 的类比："等价之于逻辑，如同等式之于算术与代数"。
- 真值表法证等价的完整示范（必须进正文）：(φ∧ψ) ∨ ¬φ ≡ φ⇒ψ，逐列算出两边都是 T F T T。
- 反直觉点/边界：真值表法只是特例，**一般情形下证等价很难**，要基于语句含义构造证明（字幕明说）。

**核心概念 B：蕴含的术语族（本讲实际重心）**

以下全部表示 φ ⇒ ψ（φ 前件、ψ 后件）：
1. if φ, then ψ（直白）
2. φ is sufficient for ψ（充分）
3. φ only if ψ ——**≠ if ψ then φ**，"if 跟着 ψ 走"，加 only 后方向反转（环法自行车例：参赛 only if 有车——真；有车就能参赛——假）
4. ψ if φ（语序翻转，后件在前）
5. ψ whenever φ（语序翻转）
6. ψ is necessary for φ（必要；有车是参赛的必要条件但不充分）

等价的术语：φ is necessary and sufficient for ψ；φ if and only if ψ；缩写 **iff**（数学家的标准缩写）。
- Devlin 强调：这套术语不止用于数学，还出现在法律文件、科学论证、分析性讨论中；掌握后"几乎所有数学文献你至少能读懂它在说什么"。
- 实践注记：数学家日常把 ⇒ 当 implies、⇔ 当 equivalent 的缩写用，之所以安全，是因为条件句/双条件与真蕴含/真等价的差异只在正常数学实践中不会出现的情形里。
- 讲内小测（四部分，全部可转化为自测）：
  - n 为 10 的倍数的必要条件：①5 的倍数、③偶数且 5 的倍数、⑤n² 是 100 的倍数（**1,3,5**）。
  - 充分条件：②20 的倍数、③、④100 的倍数、⑤（**2,3,4,5**）。
  - 充要条件：③⑤。
  - 找前件（"谁在做蕴含"）：如 "Keith cycles only if the sun shines" 中前件是 Keith cycles（看见我骑车 ⇒ 天晴）；"Amy arrives…" 中前件是 Amy arrives。

### 04 · Tutorial for Assignment 3（作业讲解）

- **Q1：把报纸标题形式化**（8 小题，主题：贸易协定 T、美元强 D、人民币强 Y）。要点：
  - a. 新贸易协定将使两国货币走强：T ⇒ (D∧Y)。
  - b. 美元强意味着人民币弱：D ⇒ ¬Y。
  - c. 因美元走弱消息贸易协定破裂：¬D ⇒ ¬T（注意 "on news of" 的方向）。
  - d. 若签署协定则不可能两者都强：T ⇒ ¬(D∧Y)。
  - e. "but" = ∧；"following" 有两种合法解读：纯合取 (¬D∧Y)∧T，或因果 T ⇒ (¬D∧Y)——Devlin 明说两种都可辩护。
  - f. 签约后人民币升则美元跌：T ⇒ (Y升 ⇒ D跌)，也可写 (T∧Y升) ⇒ D跌，两者可用真值表证等价。
  - g. 两者联动：T ⇒ (D升 ⇔ Y升)；⇔ 是两个方向条件句的缩写。
  - h. "对一边有利但没人知道哪边"：**异或**——(D∨Y) ∧ ¬(D∧Y)（这是早期作业里"让很多人吃苦头"的点）。
  - 常见错法：把标题的省略式日常语言直接按因果读，方向写反；忽视 "but=and"；异或写成可兼或。
  - Devlin 态度：自然语言→形式语言本质上有解读空间，"你的答案可与我的不同，能辩护就行"。
- **Q2+Q3**：真值表证 **φ⇒ψ ≡ ¬φ∨ψ**（两列都是 T F T T）。
- **Q4+Q5**：真值表证 **¬(φ⇒ψ) ≡ φ∧¬ψ**（F T F F）。Devlin 点明：这正解释了 Lecture 3 为什么要靠 "does not imply" 来推假前件那两行——当时就是在利用这个等价。
- **结尾谜题**：女人黑路开车、没开车灯、无月无星、路上睡着黑狗，她却绕开了——怎么知道的？线索：注意语言传达的信息。**答案字幕未明说**（经典答案：当时是白天）。

### 05 · Tutorial for Assignment 4（作业讲解，挑讲 Q6、10、12、14）

- **Q6：写否定/否认（denial）**：
  - a. "34159 是素数" → "34159 不是素数 / 是合数"。（原命题本身为真，但题目只问否定。）
  - b. "玫瑰红且紫罗兰蓝" → "玫瑰不红**或**紫罗兰不蓝"（德摩根；英语别扭但正确）。
  - c. "如果没有汉堡，我就吃热狗" → 否定 = 前件 ∧ 后件的否定 = **"没有汉堡，但我也不吃热狗"**。陷阱：前件本身带否定（"没有汉堡"），Devlin 自己演示时差点滑倒。常见错法：写成"如果有汉堡，我就不吃热狗"（这是换了前件，不是否定）。
  - d. "Fred 会去但不玩"（but=and）→ "Fred 不去或他会玩"；更自然的说法是 "Fred 会玩或者他不去"（日常会脑补因果，超出纯否定）。
  - e. x<0 或 x>10 → **0 ≤ x ≤ 10**。陷阱：negative 的否定是 non-negative 不是 positive（有 0）；>10 的否定是 ≤10 不是 <10。符号比英语干净得多。
  - f. "我们会赢第一场或第二场" → "两场都输"。
- **Q10(b)：不用真值表的等价证明（双向演绎，必须进正文作示范）**：φ⇒(ψ∧θ) ⟺ (φ⇒ψ)∧(φ⇒θ)。左→右：由 φ 推出 ψ∧θ，合取可拆出各合取支，链式得 φ⇒ψ 与 φ⇒θ；右→左反向同理。留 Q10(c) 给读者。Devlin 训诫：**不要换符号套答案**（"高中也许行得通，大学数学行不通"），要理解方法本身。（注：Q10 完整题干字幕未明说，以上是按其口述重建。）
- **Q12：逆否命题（contrapositive）**——翻转并加否定，与原命题**逻辑等价**：
  - 矩形全等 ⇒ 面积相同 的逆否：面积不同 ⇒ 不全等（皆真）。
  - 直角三角形（c 最长）⇒ a²+b²=c² 的逆否：a²+b²≠c² ⇒ 非直角。
  - 2ⁿ−1 是素数 ⇒ n 是素数 的逆否：n 非素数 ⇒ 2ⁿ−1 非素数。
  - 人民币升 ⇒ 美元跌 的逆否：美元没跌 ⇒ 人民币不会升。
- **Q14：逆命题（converse）**——只翻转不否定，**不保证等价**：
  - "面积相同 ⇒ 全等"：原命题真、逆命题**假**（反例存在）。
  - 勾股定理的逆（a²+b²=c² ⇒ 直角）：**真**——因为原命题本来就是等价，逆命题只是等价的另一半；只有原本就是等价时，逆才同真值。
  - 货币例：美元跌 ⇒ 人民币升，不必然（除非两种货币有联动机制）。
  - 练习目的不是写对（写对很容易），而是用实例体认"逆否等价、逆不等价"。

## 4. 自测题素材库（6–10 题，源自 tutorials 与讲内小测）

1. **概念辨析**｜φ⇒ψ 在哪几种真值组合下为真？答：TT、FT、FF；仅 φ 真 ψ 假时为假。常见错法：认为前件假时条件句"无意义"或"为假"。
2. **判断**｜"如果三角形有四条边，那么正方形有五条边"是真命题吗？答：真（假⇒假）。常见错法：按日常因果判断，说"这句话不通所以不成立"。
3. **判断**｜"如果欧几里得生于某年，那么矩形有四条边"是真命题吗？答：真——后件为真，则无论前件真假条件句都真。常见错法：纠结前件真假未知。
4. **辨析（方向）**｜"Keith cycles only if the sun shines" 中谁是前件？答：Keith cycles（看见我骑车⇒天晴）。常见错法：把 only if 当 if，方向写反。
5. **应用**｜对自然数 n：下列哪些是"n 是 10 的倍数"的必要条件、充分条件、充要条件？①5 的倍数 ②20 的倍数 ③偶数且 5 的倍数 ④100 的倍数 ⑤n² 是 100 的倍数。答：必要 1,3,5；充分 2,3,4,5；充要 3,5。常见错法：必要/充分方向混淆（必要条件 = n 是 10 的倍数 ⇒ 条件）。
6. **形式化**｜把报纸标题符号化：(a)"因美元走弱的消息，贸易协定破裂"；(b)"新贸易协定对一边有利，但没人知道哪边"。答：(a) ¬D ⇒ ¬T；(b) (D∨Y) ∧ ¬(D∧Y)（异或）。常见错法：(a) 方向写反成 ¬T ⇒ ¬D；(b) 漏掉 ¬(D∧Y) 写成可兼或。
7. **否定**｜写出"如果没有汉堡，我就吃热狗"的否定。答："没有汉堡，但我也不吃热狗"（前件 ∧ 后件的否定）。常见错法：写成"如果有汉堡，我就不吃热狗"——前件里藏着的否定被扔掉了。
8. **否定（计算）**｜否定"x<0 或 x>10"。答：0 ≤ x ≤ 10。常见错法：把 negative 的否定写成 positive（漏了 0）；把 >10 的否定写成 <10（漏了 =10）。
9. **迁移/辨析**｜写出"若两矩形全等则面积相同"的逆否与逆，并判断各真假。答：逆否"面积不同⇒不全等"（真，与原命题等价）；逆"面积相同⇒全等"（假，可举反例）。常见错法：以为逆命题与原命题等价；把逆否写成"不全等⇒面积不同"（只否定没翻转）。
10. **讲解输出（费曼出口）**｜向一个没学过逻辑的人解释：为什么"前件为假时条件句算真"，用"如果明天下雨我就带伞"造一个让对方接受的说法。答案要点：只有当"天下雨了而你没带伞"时才算食言；不下雨时无论你带没带伞，承诺都没被违背。常见错法：只会背真值表，说不出"食言/违背承诺"这层直觉。（本题的解释框架为讲义作者补充，字幕未明说。）

附：Tutorial 3 结尾谜题（黑路黑狗）可作趣味机动题，**答案字幕未明说**（经典答案：当时是白天——"没有月亮和星光"并未说不是白天）。
