# Illustration suggestions

Prefer original schematics, simple diagrams, or public-domain/open-license visuals.

## Good insert points

| Chapter | Illustration idea | Why it helps |
|---|---|---|
| 颜色：超越视觉 | Retina -> visual cortex pipeline | Shows that color is constructed from a signal path, not "seen directly". |
| 知觉：超越理解 | Rubin vase / Necker cube | Makes object-background competition concrete. |
| 错觉：超越事实 | Checker shadow illusion / ambiguous figure | Shows why contextual inference creates systematic error. |
| 记忆：给我一杯忘情水 | Forgetting curve or encoding-to-retrieval loop | Makes the coding-storage-retrieval cycle easy to scan. |
| 重构：那些不真实的回忆 | Source-monitoring sketch | Shows how memory content and source can split apart. |
| 大脑中有记忆开关吗？ | Hippocampus-thalamus-cortex sleep loop | Connects sleep oscillations to consolidation. |
| 时间都去哪儿了？ | Event density timeline | Shows why busy time feels different from empty time. |
| 梦：你有第六感吗？ | REM/NREM cycle diagram | Helps distinguish when dreams are more likely. |
| AI / 具身智能桥接段 | Perception-memory-action loop | Shows how modern embodied AI reuses the same loop that classical psychology describes. |

## Style rule

- One visual per dense concept is enough.
- Keep visuals schematic, not decorative.
- If a diagram can be drawn in 30 seconds, it belongs in the handout.

## If you need a source image

- Use open-license figures when possible.
- Otherwise redraw the idea as a clean schematic.
- Do not copy textbook art just because it is convenient.
