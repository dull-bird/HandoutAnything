# 出处与拓展阅读排版规范

讲义是浓缩讲解，但读者必须能**按图索骥**：定理证明想看完整版去哪翻、数据从哪来、想深造下一步读什么。**章节级出处与拓展阅读随单元（每一天/每一讲）提供**——读者学完一天，当天就能拿到当天的出处和下一步读物；同时在**参考答案之前**附一节卷尾**参考文献**总表，把所有书目与文献的版本信息（版次、出版社、ISBN）按专业引用规范一次性给全。本规范定义两样组件：**行内出处标签** `\src{}`、**单元出处与拓展阅读盒** `reading`，以及卷尾参考文献节的排版约定。设计目标与 code-blocks.md 一致：与现有盒子体系视觉一致、零额外依赖（不引入 BibTeX，xelatex 两遍即出）、跨平台可复现。

## 1. 什么内容必须有出处（方法论 §5.5）

| 必须有出处 | 不需要出处 |
|---|---|
| 定理、引理及其证明（非讲义作者原创推导） | 定义级常识（如"速度是位移的变化率"） |
| 数据、实验结论、统计结果 | 讲义自己当场完成的推导 |
| 转述材料的观点、主张 | 讲义作者自己的类比与讲解 |
| 引用的原文、图表、例题（改编自原书时点名） | |

出处要给**可翻到的定位**：章/节号、页码、或视频时间戳（`12:34`），只写书名不算合格。

## 2. Preamble 片段（原样粘贴，放在 tcolorbox 之后）

```latex
\tcbuselibrary{skins}   % reading 盒的左侧竖条需要 enhanced 皮肤（若已为 codeblock 引入则跳过）

% 出处/拓展阅读配色（讲义既有调色板之外只新增两色）
\definecolor{refaccent}{HTML}{7c3aed}  % 出处主色：紫（与蓝/橙/绿三色盒区分）
\definecolor{refbg}{HTML}{f3e8fd}      % 出处标签底：浅紫
\definecolor{readbg}{HTML}{faf5ff}     % 拓展阅读盒底：近白紫

% 行内出处标签：\src{《微积分》第一册 §3.2 定理 2}
\newcommand{\src}[1]{%
  {\small\colorbox{refbg}{\color{refaccent}出处：#1}}}

% 单元出处与拓展阅读盒（标题固定为"本单元出处与拓展阅读"）：
%   \begin{reading} ... \end{reading}
\newtcolorbox{reading}{
  enhanced,
  colback=readbg, colframe=readbg, boxrule=0pt, arc=2pt,
  borderline west={2pt}{0pt}{refaccent},   % 左侧 2pt 紫竖条
  left=8pt, right=8pt, top=5pt, bottom=5pt,
  fonttitle=\small\bfseries, coltitle=refaccent,
  colbacktitle=readbg, toptitle=4pt,
  title={本单元出处与拓展阅读}}
```

注意事项（实测踩过的坑）：

- `borderline west` 只在 `enhanced` 皮肤下渲染，缺了竖条静默消失（不报错）。
- **自定义盒子的标题参数只能出现在 `title={#1}` 这种"取值位置"**：若把 `#1` 平铺成选项列表里的独立一项（如 `title={拓展阅读}, #1`），中文标题会被 pgfkeys 当未知键直接报错。本规范把标题固定进盒定义，正是为了避开这个坑，不要自行加回可选参数。
- 不加 `breakable`：它需要额外 `\tcbuselibrary{breakable}`，盒子内容量被使用规则限死（每单元 3–5 行），跨页需求用拆盒解决。
- `\src{}` 内容走 LR 模式**不会折行**，只放短标签（书名 + 章节号）；长说明写正文，不要塞进 `\src`。
- 紫色系刻意区别于现有盒子：蓝 = 核心概念、橙 = 自测、绿 = 计算、紫 = 出处/拓展，读者扫一眼颜色就知道这块是"往外指"的。

## 3. 使用规则

1. **出处就近标**：定理/数据/转述观点**首次出现处**紧跟 `\src{书名/来源 + 章节号}`。行内标签负责"指路"，单元盒负责"给全貌"。
2. **每个单元末尾一个 reading 盒**（位置在"今日自测"之后）：盒内两部分——
   - **本单元出处**：当天出现的定理/数据/观点各一条，写全"来源 + 章节号 + 一句话为什么读它"；当天无外部来源就写"本单元内容为讲义原创讲解"。
   - **拓展阅读**：1–2 条，每条写清三件事——读什么（书 + 章/节）、读多少（"读到 §4.3 即可，后面超纲"）、需要什么前置（"学完第 3 讲再来"）。写不出这三件事，这条就不该有。
3. **章节号不堆到卷尾**：不用跨单元的全局编号 `[1][2]`——章节级定位随单元就地给全，读者当天学完当天拿走。同一本书在多个单元出现时，在各自单元的盒里重复写一遍书名章节号，这是刻意冗余：读者不必回翻。版本信息（版次/ISBN）只在卷尾参考文献节给一次，不重复。
4. **拓展阅读只列把关过的书**：确认过版本、章节号真实存在、难度匹配目标读者。不确定章节号就去查证，查不到就不列——列错章节号比不列更糟。
5. **论文类来源**与 references/research-inserts.md 衔接：研究进展插入的论文出处写进对应单元的 reading 盒。
6. **禁用 BibTeX**：讲义是自包含单文件交付，手工列表比引入 `.bib` + bibtex 编译步骤更可靠。
7. **卷尾参考文献节（必做，放在参考答案之前）**：把全讲义用到的书目与文献汇总成一节 `\section*{参考文献}`（并 `\addcontentsline` 进目录），位置在 `\section*{参考答案}` **之前**。规范：
   - **专业引用格式**：按 APA 风格手工排版（作者. (年份). 书名（译者）. 出版社. ISBN），悬挂缩进用 `itemize[label={}, leftmargin=2em, itemindent=-2em]` 实现，不用全局编号。
   - **书名尽可能用中文**（附原文名便于检索），**论文保留原始英文标题**（便于数据库检索）。
   - **版本信息给全**：版次、译者、出版社、年份、ISBN；19 世纪等早期文献无 ISBN 时明写"无 ISBN"；只列查证过的条目，查不到版本信息就不列。
   - 可分两组："书目"与"期刊论文与历史文献"；非正文引用的配套资源（视频/习题库）不进此节，在卷尾资料注里给。

## 4. 单元盒骨架（放在每个单元的"今日自测"之后）

```latex
\begin{reading}
\textbf{本单元出处}
\begin{itemize}
  \item 中值定理及其证明：《微积分》（第一册）§3.2 定理 2——本讲义省略的严格证明在这里，约 6 页。
  \item 例 3（边际成本）改编自同书 §3.4 例 7，数字已改小便于手算。
\end{itemize}
\textbf{拓展阅读}
\begin{itemize}
  \item \textbf{想看更严谨的证明}：《数学分析》第 5 章——严格论证细节全补齐；学完第 4 讲后再读。
  \item \textbf{对应用感兴趣}：《XXX》§2.1–2.3——三个工程实例，只需本单元的基础。
\end{itemize}
\end{reading}
```

## 5. 卷尾参考文献骨架（放在 `\section*{参考答案}` 之前）

```latex
\section*{参考文献}
\addcontentsline{toc}{section}{参考文献}

本节按专业引用规范（APA 格式改写）汇总本讲义用到的全部书目与文献：书名用中文（附原文名便于检索），论文保留原始英文标题。

\textbf{书目}
\begin{itemize}[label={}, leftmargin=2em, itemindent=-2em, itemsep=3pt]
  \item 作者, A.（中文名）. (年份). \emph{中文书名（版次）}（译者 译）. 出版社. ISBN 978-x-xxxx-xxxx-x.（英文原版 \emph{Original Title}，出版社，年份）
\end{itemize}

\textbf{期刊论文与历史文献（保留原始标题，便于检索）}
\begin{itemize}[label={}, leftmargin=2em, itemindent=-2em, itemsep=3pt]
  \item Author, A. B. (年份). Article title. \emph{Journal Name}, 卷(期), 页码.
\end{itemize}
```

## 6. 与质量门的衔接

- `review_handout.py` 逐单元检查：单元块内没有「出处」「参考文献」「拓展阅读」「延伸阅读」任一字样记 warning——章节级出处必须随单元提供；同时检查 `\section*{参考答案}` 之前是否有 `\section*{参考文献}`，缺了记 warning。
- `\src{}` 与 `reading` 盒不影响 lint 的引号/省略号检查；书名号《》照常使用。
- 结构位置：reading 盒在每个单元的"今日自测"**之后**——当天内容的最后一块，学完当天就拿到当天的出处与下一步读物。
